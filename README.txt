                             AllBinary Platform Wren

What is it?

This repository contains code generated by the AllBinary Platform for support in Wren.  
This repo is used to allow developers to skip the Wren code generation step.

What are some example games with this Wren code?

https://allbinary.itch.io (The downloads with "-wren" in the filename are Wren only builds. Currently that only includes nothing. Also the Wren builds are not available on Google Play or other stores.)
